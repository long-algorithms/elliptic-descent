# Relative 4-descent for two irreducible quadratic factors

This is **v0.4 development step 2**, following the [etale arithmetic
backend](etale-arithmetic.md). `relative_four_descent` now supports squarefree
quartics of type `(2,2)` as well as irreducible quartics. The package version
remains **0.3.0**: rational-root cases and the complete v0.4 release are still
separate work. This is not full curve-level 4-Selmer-group assembly.

## Input and exact marking

Let `f=a*g_1*g_2`, where `a` is a nonzero rational and `g_1,g_2` are distinct
monic irreducible quadratics over Q. The fixed source is

\[
 C:Y^2=F(X,Z),\qquad A=\mathbb Q[t]/(f)=K_1\times K_2.
\]

The original `f` and its leading coefficient are retained. Polynomial factors
are labelled even when the two fields are isomorphic; they are not merged or
permuted as an unrecorded target automorphism. The input includes the canonical
quartic-to-Jacobian map via `QuarticTwoCover`, as in the irreducible API.

```python
from elliptic_descent import relative_four_descent

# (t^2-2)(t^2-3); coefficients in ascending order.
result = relative_four_descent((6, 0, -5, 0, 1), proof=True)
assert result.factorization_type == (2, 2)
assert result.complete and result.certified
assert result.verify_evidence()
assert len(result.unoriented_coverings) == 1
assert len(result.coverings) == 2
```

The standard square-class construction for this domain is explicitly treated
by Merriman--Siksek--Smart, Section 4.2. Here the CRT presentation and the
original quartic power basis are two representations of the same algebra.
Our geometric constructor, real test, finite-place solvers and covering maps
are shared with the irreducible path, not rewritten as approximate versions.

## One combined norm and one diagonal scalar quotient

The backend computes the full direct sum

\[
 A(S,2)=K_1(S_1,2)\oplus K_2(S_2,2),
\]

including every prime above each rational prime in S and the class-group
contribution in both factors. The single affine norm condition is

\[
 N_{K_1/\mathbb Q}(\xi_1)N_{K_2/\mathbb Q}(\xi_2)=a r^2.
\]

It would be incorrect to require each component norm to be a square. Likewise,
we quotient by the image of **diagonal** rational scalars, not by independent
scalars in the two components. The image is computed in actual square-class
coordinates, retaining dependencies; its dimension need not be `|S|+1`.
For `(t^2-2)(t^2-8)`, for example, 2 is a square in both component fields.

The conservative support uses the discriminant of the **whole quartic**, not
just the two factor discriminants. It therefore includes the inter-factor
resultant primes. Outside S the product order is etale; the finite-support
argument in [arithmetic.md](arithmetic.md) works componentwise and shows that
every everywhere locally soluble lift has a representative in `A(S,2)` up to
a rational scalar. Conversely, if a rational scalar has image in `A(S,2)`, its
valuations outside S are even because all ramification indices there are one.
Thus `-1` and the primes of S generate every scalar identification required
within this finite space.

## Fixed-target equivalence and the orientation lemma

For a norm pair `(xi,r)` with `N_A(xi)=a*r^2`, the scalar-square relation is

\[
 (\xi,r)\sim(c v^2\xi,\;c^2N_A(v)r),
 \qquad c\in\mathbb Q^*,\quad v\in A^*.
\]

It gives the exact coordinate transformation `U_old=v*U_new`. All four
coefficient quadrics scale by c, and the map to C scales in weighted
coordinates by `(c,c^2,c)`. The target C is fixed pointwise. The converse
classification is the same labelled norm-pair descent used in the general
construction: an isomorphism over C respects the pulled-back divisor class
and its four conjugate rank-one forms. It yields this scalar-square relation;
one must not additionally identify factor permutations or target translations.
See Fisher, Sections 3--5, and the [general contract](relative-descent.md).

**Lemma.** In a product of two quadratic fields, a scalar-square stabilizer
cannot reverse the sign of r.

Suppose `c*v^2=1`. Put `d=1/c`, so `v_1^2=v_2^2=d`.
If d is a rational square, both `v_i` are rational and
`N_{K_i/Q}(v_i)=d`. If d is not a rational square, each quadratic field must be
`Q(sqrt(d))`, and the conjugate of `v_i` is `-v_i`, so its norm is `-d`.
In either case the product is `N_A(v)=d^2`. Hence

\[
 c^2N_A(v)=1,
\]

not -1. This includes the case of two distinct polynomial factors defining
isomorphic quadratic fields, including imaginary ones. For a quartic field
the same identity follows by considering the degree-one or degree-two subfield
generated by v. Therefore the two norm-witness signs remain inequivalent in
both currently supported factorization types.

Each accepted scalar-square class consequently gives **two** entries in
`result.coverings`. `result.unoriented_coverings` explicitly identifies the
target involution `Y -> -Y` and contains one. The `OrientationCertificate`
stores the canonical factorization and checks the hypothesis against the
actual source, not just an abstract isomorphism type. It certifies the use of
this lemma, not class-group completeness or local solubility.

The lemma must not be extended to rational-root types: a sign flip in a
one-dimensional factor has square 1 and norm -1. Those types continue to raise
`NotImplementedError` before invoking the complete descent backend.

### Explicit equivalence witnesses

`ScalarSquareEquivalence` verifies the multiplier's invertibility, its
multiplication matrix, signed norm relation, all four quadratic identities,
and the weighted covering-map identities. The verifier uses the CRT/product
norm, independently of the construction's multiplication-matrix norm.

```python
from elliptic_descent import construct_four_cover, EtaleQuarticAlgebra
from elliptic_descent.equivalence import scalar_square_change

f = (6, 0, -5, 0, 1)
A = EtaleQuarticAlgebra(f)
D = construct_four_cover(f, (1, 0, 0, 0))
v = A.embed_factor_unit(0, (0, 1))
D1, witness = scalar_square_change(D, -2, v)
assert witness.verify(D, D1)
```

Outside a stabilizer, `N_A(v)` can be negative. It is essential to preserve the
**signed** witness `c^2*N_A(v)*r` in a change of model, not replace it by the
positive square root. The tests include negative norms, inverse transformations,
corrupted witnesses, component sign flips, and nonsquare scalar stabilizers.

## Completeness and proof status

The norm-pair construction and finite support theorem apply to this quadratic
product. The factorwise Selmer spaces exhaust the global square classes; the
diagonal scalar quotient is exact; the lemma accounts for the two orientations;
and every quotient representative is checked locally. The shared complete
local procedure has no default work/depth cutoff and terminates on smooth
models by its compactness/Hensel argument. These facts establish soundness,
exhaustiveness and nonredundancy in the declared fixed-target equivalence.

The existing `complete`, `certified`, `unresolved`, proof-mode and budget rules
remain in force. Conditional class-group computations remain conditional;
unknown local decisions are not dropped. `verify_evidence()` audits exact
geometry/local records and the orientation hypothesis, **not** an independent
second computation of the class groups. Manually constructed status objects
are not proofs. The existing irreducible arithmetic backend is retained for
type `(4,)`; no change of basis is forced on those computations.

## Independent tests and provenance

For a source C with a verified rational point, choosing that point identifies
C with its Jacobian E. Its everywhere locally soluble relative 2-coverings
are then a torsor for `Sel^(2)(E/Q)`, and their number is

\[
 \#\{\text{fixed-target oriented covers}\}=2^{\dim_{\mathbb F_2}\operatorname{Sel}^{(2)}(E/\mathbb Q)}.
\]

The new genuine-Sage tests compare the left side from this implementation to
**eclib's `selmer_rank()`**, not to a rank bound or to another invocation of our
number-field backend. Six fixtures have explicit rational points, including
nonmonic sources and points at infinity. This is a cardinality check, not
class-by-class equivalence to eclib output.

| Source polynomial | Exact rational source point `(X,Y,Z)` | Unoriented regression count |
|---|---|---:|
| `(t^2-2)(t^2-3)` | `(1,1,0)` | 1 |
| `(t^2-2)(t^2-8)` | `(1,1,0)` | 2 |
| `2(t^2-2)(t^2-3)` | `(1,2,1)` | 2 |
| `(t^2+1)(t^2+2)` | `(1,1,0)` | 1 |
| `(t^2-2)(t^2+3)` | `(1,1,0)` | 1 |
| `2(t^2+1)(t^2+3)` | `(1,4,1)` | 2 |
| `-(t^2+1)(t^2+2)` | none: real obstruction | 0 |
| `3(t^2+1)(t^2+2)` | none: obstruction modulo 8 | 0 |

The last two are **locally insoluble sources**, not nontrivial Sha examples.
The modulo-8 obstruction is independently checked over all primitive `(X,Z)`
residues; its descent has candidates requiring actual local rejection. The
real-obstructed source already has an empty norm fibre. The existing 571a1
irreducible regressions continue to test locally soluble sources with empty
higher descents. No execution of Magma is claimed for the new fixtures.

Additional checks cover real signatures `(4,0)`, `(2,1)`, `(0,2)`, translations,
square rescaling, diagonal scalar-image dependencies, both proof modes, explicit
budget exhaustion, malformed orientation evidence, and generic Groebner audits
on positive models. Existing etale tests retain class-group 2-torsion cases.

```sh
sage -pip install -e '.[test]'
ELLIPTIC_DESCENT_REQUIRE_SAGE=1 sage -python -m pytest -q
sage -python benchmarks/two_quadratic.py --verify --repeats 3
```

The JSONL records include the actual scalar-image rank, total/accepted class
counts, support, local work and model changes, solver time, evidence/eclib
verification time, proof assumptions, environment and cumulative process memory.
These are in-process repetitions, not cold-cache or cross-system speed claims.

bases for replay; their JSON files are not standalone class-group certificates.
