# v0.5 plan — curve-level 4-Selmer computation

This is an acceptance specification, not a claim that v0.5 is implemented.
The package remains version 0.4.0 while the following eight development steps
are reviewed independently. Development-step numbers are not GitHub PR numbers.

## Target and representation contract

Input an elliptic curve E over Q in an exact Weierstrass model. Preserve its
identity as the user's target, even when arithmetic uses a minimal model.
The target output is Sel^(4)(E/Q) as a finite abelian group with generators,
invariant factors, addition, inverses and element orders; exact arithmetic
coordinates; and explicit marked covering representatives available on demand.
Also retain the map to Sel^(2)(E/Q), the relevant Kummer/torsion maps, and the
labelled Cassels--Tate pairing on the chosen 2-Selmer coordinates.

An isomorphic abstract curve, equal j-invariants, a list of covering equations,
or the right group cardinality is not sufficient. Markings and group elements
must agree under exact maps. Relative diagrams over one fixed quartic and
classes over E have different equivalences: global assembly must implement the
latter explicitly. It must not concatenate relative output lists and assume
that every entry is a distinct global class.

## Eight reviewable steps

| Step | Deliverable | Required verification |
|---|---|---|
| 1 — completed | Marked curve/covering interfaces, exact model changes, cubic presentation conversion, zero-class 2-cover | Inverse and commuting diagrams; original target retained; branch/infinite/torsion points; false markings rejected |
| 2 — completed | Certified labelled 2-Selmer spaces and Kummer data | Documented completeness/independence; coordinate round trips; torsion classes |
| 3 — completed | Covering representative for every 2-Selmer vector | Zero, basis and sums; exact labels and marking; basis-change invariance |
| 4 — completed | Labelled Cassels--Tate pairing and radical | Alternation, bilinearity, local evidence, basis changes; liftability cross-checks |
| 5 — completed | Assemble fibres as global 4-Selmer classes | Correct global equivalence, rational-torsion action, kernel/image and exact-sequence accounting |
| 6 — completed | Explicit 4-Selmer group arithmetic | Relations, orders, generators and group law matched to covering representatives |
| 7 — current | Public curve-level API and arithmetic reuse | Complete/conditional/partial states, on-demand representatives, no hidden assumptions |
| 8 | Independent validation, benchmark and release audit | Group structure and maps, full regression corpus, reproducible distributions |

Steps can be split further when needed for mathematical review. No acceptance
gate is weakened merely to preserve the number eight. Tests accompany every
step; step 8 is not when testing starts.

## Step 1 scope

[Marked-covering interfaces](marked-coverings.md) add exact Weierstrass changes,
translations, identity-class quartic presentations and explicit cubic conversion.
A marked 2-cover is constructed from a canonical quartic map, a specified
Jacobian isomorphism, and a rational target translation. An imported cubic or
quartic map must equal that construction in the exact function field; neither
its degree nor merely satisfying the target equation is used as a substitute.

The zero class is [2]:E->E, **not** the degree-one identity map. The marked
relative solver composes its output back to the user's E; it does not enumerate
the other 2-Selmer classes or assemble the full 4-Selmer group.

Sage normalization may choose an isomorphism, but its exact parameters are
retained and independently checked. Imported PARI markings require explicit
isomorphism/translation data; they are not guessed from the Jacobian or a curve
label. Recovering those data automatically and certifying imported basis
completeness belong to later interfaces. The legacy low-level quartic API
continues to reject degree-three input: conversion is explicit and separate.

## Step 2 scope

[Labelled 2-Selmer arithmetic](two-selmer.md) computes the entire cubic-algebra
norm kernel and tests every class locally. The result has actual arithmetic
coordinates, independent basis checks, model transport, Kummer maps and
rational torsion kernels/halves. It does not assume that a PARI covering list
comes with certified group labels. Auxiliary quadric models provide local
tests; the [step 3 interface](selmer-quartics.md) now converts every labelled
class to a binary quartic with its marking. Full 4-Selmer assembly remains later work.

## Step 3 scope

[Labelled quartic representatives](selmer-quartics.md) parametrize the conic in
each accepted cubic-algebra model and retain its exact inverse maps, arithmetic
class and marking on the original E. They handle zero, basis elements and all
sums, without asking for a rational point on the genus-one covering. Coordinate
and basis changes preserve actual class labels; conditional provenance survives
relative descent. These are representatives above fixed intermediate classes,
not an implementation of global 4-Selmer fibre equivalence or a pairing.

## Step 4 scope

[The labelled Cassels–Tate pairing](cassels-tate.md) computes each independent
matrix entry from Fisher's formula for two labelled classes and their sum.
Normalization, arithmetic labels, product square roots, support and local
Hilbert-symbol evidence are checked exactly. Basis changes retain explicit
coordinate maps, and a partial local computation has no reported radical.
The radical identifies the image of Selmer-4, not its group structure. Tests
compare direct evaluations on sums, changed models, independent PARI ranks,
and unpruned relative-lift computations. Global fibre equivalence remains step 5.

## Step 5 scope

[Global fibre assembly](four-selmer-fibres.md) computes actual rational
2-torsion actions on every accepted relative diagram and quotients their
verified permutations. Coordinate matrices witness each global equivalence.
The zero fibre carries the actual map from cubic-algebra 2-Selmer classes,
including its torsion Kummer kernel; projection and pairing exclusions retain
labels. Partial/conditional provenance remains explicit. These are global
classes and exact-sequence maps, not yet addition or invariant-factor generators.

## Invariants for later steps

Arithmetic class coordinates are authoritative; curve equations are their
presentations. A 2-Selmer basis does not supply equations for every sum. In
particular, the liftable subspace may contain a sum of basis vectors but none
of the selected basis vectors individually. Obtain labelled classes and a
labelled pairing matrix, not just a pairing rank or Mordell--Weil rank bound.

Implement the exact cohomological maps in

    E(Q)[2] -> Sel^(2)(E) -> Sel^(4)(E) -> Sel^(2)(E).

Rational 4-torsion affects the first map's kernel. Cardinalities are necessary
checks, not replacements for the maps. In particular, distinguish the map
Sel^(4)->Sel^(2), the map Sel^(2)->Sel^(4), and multiplication by 2 inside the
4-Selmer group. A group of order four need not be cyclic.

Retain an exhaustive small-case route alongside pairing-based pruning. Compare
basis changes, alternate Weierstrass models, and independently established
fixtures. Two calls to the same backend through different interfaces are not
independent algorithms. Extend cases with no rational 2-torsion, cyclic/full
rational 2-torsion, rational 4-torsion, and genuinely order-four Selmer elements.

## Proof and performance boundaries

Certified computations require justified finite support, certified number-field
arithmetic, exact local decisions and complete class/equivalence accounting.
A budget limit yields partial data, not an obstruction. Retain assumptions
through all maps and operations. Point search failure cannot decide Selmer
membership or triviality of Sha.

Measure separate arithmetic, class construction, pairing, equivalence, group
assembly and verification costs. Fix proof mode and task scope in comparisons;
retain candidate dimensions, coefficient sizes, caches, versions and memory.
All v0.4 regressions remain enabled throughout development.

General minimization/reduction, large-height point search, exact rank and
saturation, number-field base curves, and a C++ rewrite are not prerequisites
of this milestone. The [reference bibliography](descent-references.md) and
[completeness specification](completeness.md) remain the mathematical source map.

## Step 6 scope

[Exact group arithmetic](four-selmer-group.md) ties addition to the actual
covering classes using checked finite Galois cocycles. It includes inverses,
orders, invariant-factor generators, coordinates, relations and compatibility
with the existing exact-sequence maps. Only uniquely forced small/kernel/image
cases avoid field discovery. The merged implementation has exact evidence
replay and genuine Sage integration gates; these remain regression requirements.
The final release
audit remains a separate obligation.

## Step 7 scope

[The curve-level API](public-api.md) coordinates all stages, retains exact
parent links and original models, and distinguishes intermediate completion
from a complete unconditional 4-Selmer group. Per-session caches reuse actual
arithmetic and witness objects without memoizing certification verdicts.
Partial limits preserve earlier results; only typed resource-limit exceptions
are converted to partial group results. Lower-level reference routes and all
previous acceptance gates remain available. Step 8 is the final release audit.
