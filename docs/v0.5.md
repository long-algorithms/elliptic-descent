# v0.5.0 — explicit 4-Selmer groups over Q

## Supported computation

For a nonsingular elliptic curve over Q in an exact rational Weierstrass model,
`four_descent` computes the labelled 2-Selmer space, its Cassels–Tate pairing,
the global 4-Selmer classes, and the actual group law on their marked covering
representatives. Generators, orders, invariant factors, relations, coordinates,
projection to Selmer-2 and kernel inclusion are retained. Multiplication by two
inside Selmer-4 is the composite of inclusion and projection, not projection
alone. The user's original model and exact changes of model are preserved.

The package accepts two or five rational coefficients and Sage curves over QQ.
Singular, inexact and unsupported-base-field inputs are rejected. The complete
relative interface for all five squarefree degree-four factorization patterns
remains available under the [v0.4 contract](v0.4.md). Cubic conversion is explicit.

The construction and its completeness obligations are documented in
[2-Selmer arithmetic](two-selmer.md), [quartic presentations](selmer-quartics.md),
[the pairing](cassels-tate.md), [global fibres](four-selmer-fibres.md),
[the group law](four-selmer-group.md) and [the public API](public-api.md).
The existing mathematical references and [general bibliography](descent-references.md)
remain authoritative; this guide does not replace their arguments.

## Certification and limits

`finished` means the requested stage completed. `complete` means the full group
was constructed. `certified` additionally requires unconditional parent
arithmetic and a fresh evidence check. Verification verdicts are not cached.
`proof=True` explicitly requests certified Sage number-field computations;
conditional dependencies from an earlier stage cannot be erased by a later
unconditional call. Fully rational arithmetic need not acquire a GRH assumption.

Explicit local, candidate, fibre or field-degree limits preserve partial data.
A failed resource-limited search is unknown, never proof of insolubility.
Unexpected backend/arithmetic errors raise; previously computed session stages
remain accessible. Sessions reuse work in memory but are not durable checkpoints.
No artificial limit is imposed in the complete release benchmark runs.

Full descent requires Sage; CI uses the digest-pinned Sage 10.6 image. Python
3.10 and 3.13, SymPy 1.13.0 and the exact Python/FLINT alternatives have separate
gates. The optional `fast` extra accelerates exact arithmetic, not a floating
approximation. No new mandatory dependency is introduced by this release.

## Independent validation, with its exact scope

`benchmarks/independent_mw.py` supplies a reference that does not use the package's
square-class, pairing or normal-field group-law computations. On six specified
curves, eclib supplies a 2-Selmer upper bound. Independently enumerated rational
torsion and, for the rank-one example, a checked infinite-order point attain
that bound. Thus

    dim Sel2(E) = rank E(Q) + dim E(Q)[2],

so Sha(E)[2]=0. It follows that Sha(E)[4]=0: twice an element killed by four
would be in Sha[2], and then that element itself would be in Sha[2]. The Kummer
exact sequence therefore identifies Sel4(E) with E(Q)/4E(Q). Rational torsion
and the proved rank determine that quotient without our descent machinery.
This argument is an audit of these fixtures, not a general rank algorithm.

| Fixture | Independently determined group | All named classes and sums checked |
|---|---|---|
| y^2=x^3-x+1 | Z/4 | Yes |
| y^2=x^3-x | (Z/2)^2 | Yes |
| y^2=x^3+x | Z/2 | Yes |
| y^2=x^3+4x | Z/4 | Yes |
| [0,-5,0,-16,80] | Z/2 x Z/4 | Group invariants only |
| [0,-1,1,-10,-20] | Trivial | Group invariants only |

For the four labelled cases, the audit finds exact rational points on every
returned quadric intersection, evaluates its exported marked map independently
with Sage rational arithmetic, and compares the resulting points modulo
4E(Q). Sage's exhaustive rational `division_points(4)` distinguishes classes
and determines every sum. This checks **14 actual class representatives and
52 ordered sums**, as well as all 52 pairwise separation comparisons.
A bounded covering-point search is used only to find positive witnesses; failure
fails the audit and is never converted into insolubility. All six jobs build
and install the wheel, then run outside the checkout with an import-path check.

The other comparisons retain their narrower meanings:

- eclib dimensions and PARI pairing ranks compare independently implemented
  arithmetic, but generally do not identify every named class.
- Published Magma relative-descent examples include the positive handbook case
  and the three obstructed 571a1 coverings. No new live Magma execution is claimed.
- Portable pairing/fibre/group replay rechecks our recorded exact witnesses;
  it is not independent class-group discovery or a second full descent algorithm.
- API-versus-explicit-pipeline comparisons share kernels and test integration
  and reuse. They are not independent arithmetic implementations.

The nontrivial-Sha and sixteen-class fixtures remain in the full regression
corpus; the Sha-trivial argument above is not incorrectly applied to them.
The experimental alternate torsor/theta branch is not part of this release and
is not counted as an independent successful implementation.

Primary interface references:
[Sage/eclib Selmer bounds](https://doc.sagemath.org/html/en/reference/libs/sage/libs/eclib/interface.html)
and [Sage rational division points](https://doc.sagemath.org/html/en/reference/arithmetic_curves/sage/schemes/elliptic_curves/ell_point.html).

## Required final-revision gates

Every release must have successful push/main runs at the exact release commit
for the nine workflows listed in `tools/release_gate.py`. Their artifact inventory
must contain all genuine-Sage JUnit groups, without failures, errors, skips,
duplicate test identities or missing source test functions. It also requires:

| Corpus | Required cases |
|---|---:|
| Relative descents | 22, including 14 eclib comparisons |
| Etale arithmetic | 8 |
| Marked-model normalization | 4 |
| Labelled 2-Selmer curves | 7 |
| Labelled quartic representatives | 19 |
| Pairings with PARI comparisons | 9 |
| Global-fibre constructions and replays | 8 |
| Group constructions and replays | 8 |
| Staged/warm API calculations | 4 |
| Independent rational-quotient audits | 6 |

The group corpus contains 43 global classes, 389 ordered sums and 409 parent
covering-equivalence witnesses. Its eight-class and sixteen-class examples use
the general geometric Galois-cocycle route, with common field degrees 64 and 32.
Other cases use exact-sequence shortcuts only where the retained maps uniquely
determine the law. Fresh Sage construction and separate evidence replay remain
required; no saved portable certificate replaces the discovery run.

Timings, coefficient sizes, field degrees, environment, proof mode and work
counts remain in the JSON reports. They are observations on shared CI hardware,
not fixed performance guarantees. Warm API acceptance requires zero additional
mathematical construction, not a favourable clock measurement.

## Packaging, provenance and publication

The wheel and source distribution must match the exact source byte-for-byte,
including all package modules and required documentation/tests/benchmark tools.
The installed wheel is tested outside the checkout, the sdist must rebuild,
and package/runtime versions, Python requirements and MIT metadata must agree.
The release gate reruns the distribution content audit on the downloaded CI
files and verifies their SHA256 checksums before any publication.

Publication is an explicit, trusted-main workflow. A successful single job is
not enough: every required workflow and artifact must refer to the same SHA.
Missing/running gates defer publication; failed/cancelled or mixed-revision
records are rejected. A tag at another commit is never overwritten. Files are
uploaded to a same-commit draft first; only the complete audited release becomes
public. Pull-request code cannot invoke this privileged publication path.

Release assets are the wheel, source distribution, `SHA256SUMS`, distribution
manifest, aggregate audit report and a verification bundle with exact source,
original CI artifacts and workflow provenance. No PyPI credentials or upload
are involved. The version and complete mathematical test inventory are part of
the release; a tag is not evidence of correctness by itself.

## Exclusions and trust boundary

This is a reference 4-Selmer implementation over Q, not general-base-field
descent, exact Mordell–Weil rank/saturation, a complete rational-point search,
or a practical minimization/reduction package. Arbitrary imported markings are
not automatically recovered. Large exhaustive norm spaces and normal closures
can be expensive; passing finite fixtures is not a universal runtime guarantee.

Certified units/class groups remain a trusted Sage dependency. Exact local,
covering, equivalence and cohomological verifiers check retained evidence, but
none of this constitutes formal verification, independent recomputation of all
class groups, or external mathematical peer review. No performance superiority
over Magma, PARI or eclib is claimed. These distinctions must remain visible in
future releases and optimized implementations.
